# App Workflow

1. Add Review: load admin fields, capture info/ratings/comments/photos, save images, validate → preview.
2. Review Preview: show all entries, compute average, submit → save to AsyncStorage.
3. Reviews List: list + search/sort/filters/average dropdown; open details/delete.
4. Review Detail: full view, generate PDF (printToFile → share).
5. Admin Questions: manage dynamic fields and categories.
6. Dashboard: stats and quick actions.
7. Startup migration: run if needed from `_layout.tsx`.
